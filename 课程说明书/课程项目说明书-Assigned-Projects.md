## AP1 · 交互式 2D 分形（10 分，W2 发布 → W4 末交）

### 项目目标

- 理解"应用程序 → 顶点数据 → 渲染"的最小图形程序结构；
- 掌握顶点数组（`Float32Array`）→ VBO（`gl.bufferData`）的数据组织与传递方式；
- 掌握递归细分与随机迭代（混沌游戏）两种算法生成同一图形；
- 掌握事件驱动交互：HTML 控件、鼠标、键盘。

### 任务分解

**必做（Baseline，满分 8 分）**

1. **混沌游戏**生成 Sierpinski 垫片：初始点随机，反复执行 `p = (p + 随机顶点) / 2`，至少 5000 个顶点；以 `gl.POINTS` 图元渲染。
2. **递归细分**生成垫片：实现 `subdivide(triangle, depth)`，深度可由用户输入（建议 0–6）；同一组三角形支持**点云（`gl.POINTS`）/ 线框（`gl.LINES`）/ 实体（`gl.TRIANGLES`）**三种渲染模式切换。
3. **参数面板**（HTML 控件或 lil-gui）：
   - 顶点数（点云模式）/ 递归深度（线框与实体模式）；
   - 点大小、至少 3 套配色方案；
   - 渲染模式切换控件。
4. **鼠标交互**：左键拖动平移、滚轮缩放（监听 `mousedown` / `mousemove` / `wheel` 事件自行实现）。
5. **键盘交互**：`1 / 2 / 3` 切换渲染模式；`空格` 暂停 / 继续"逐点生长"动画（点数从 0 随时间增长到设定值）。

**选做（Extension，最多 +2 分）**

- E1：推广到任意 n 边形垫片（如五边形、六边形混沌游戏），观察差异；
- E2：Mandelbrot 或 Julia 集交互探索器（缩放 + 配色映射）；
- E3：加入 3D 四面体 gasket 预览模式（为 AP2 铺垫）。

### 交付物

可运行 URL + 源码 zip + README（含两种生成算法的原理简述、交互操作说明、三种渲染模式截图各一张）。

### 评分量规（10 分制）

| 维度 | 分值 | 说明 |
|---|---|---|
| 算法正确性 | 3 | 两种方法均正确生成垫片；递归深度 ≥ 4 不崩溃 |
| 交互完整性 | 3 | 参数面板、鼠标、键盘三类交互全部可用且响应正确 |
| 代码质量 | 2 | 结构清晰、无全局变量滥用、几何 / 交互 / UI 分文件 |
| README 与演示 | 1 | 文档完整，现场演示流畅、抽问能答 |
| 选做扩展 | +2 | 按完成度给分，封顶 +2 |

## AP2 · 三维层级场景：太阳系（10 分，W5 发布 → W7 末交）

### 项目目标

- 掌握三维仿射变换与齐次坐标的组合使用（平移 / 旋转 / 缩放）；
- 掌握层级建模：模型矩阵逐层相乘，表达"物体在物体之上"的变换依赖；
- 掌握观察与投影：相机定位、透视与正交投影的差异、相机动画漫游。

### 任务分解

**必做（Baseline，满分 8 分）**

1. **层级结构**：太阳–地球–月球三级变换嵌套（模型矩阵逐层相乘，或维护简单矩阵栈）。地球绕太阳公转并自转；月球绕地球转；**地球自转轴倾斜 23.5°**——要求先在地球自身的模型矩阵上施加倾角旋转，再叠加公转轨道变换（体会"变换顺序决定结构"）。
2. **手动矩阵**：至少一处运动**不用**工具库封装好的复合函数，而是用 `MV.js` 的 `mat4` 基本变换（`rotate` / `translate` 等）手工构造并 `mult` 组合（例如月球轨道面倾角），README 中说明该矩阵的构造逻辑——对应教材 Ch4 的变换推导。
3. **表面纹理**：太阳、地球、月球各贴一张位图纹理（`gl.texImage2D` + 纹理坐标 attribute）；注意地球纹理常见的上下颠倒问题及 `UNPACK_FLIP_Y_WEBGL` / UV 处理，README 中给出解释。
4. **双投影对比**：`O` 键切换正交 / 透视投影渲染同一画面，README 附同场景两投影对比截图并说明平行线 / 近大远小的差异。
5. **相机漫游**：一段预设路径的环绕漫游动画（如绕场景一周，关键帧插值），按 `空格` 暂停 / 继续；漫游与鼠标拖拽视角可随时互相接管。
6. **参数面板**：公转速度、自转速度、轴倾角滑条；轨道线显示开关。

**选做（Extension，最多 +2 分）**

- E1：扩展为完整太阳系（≥ 6 颗行星，含土星环）与小行星带；
- E2：日食 / 月食模拟（视点切换 + 光影说明）；
- E3：虚拟轨迹球（教材 Virtual Trackball 思想）实现视角控制。

### 交付物

可运行 URL + 源码 zip + README（含层级结构图——画出变换嵌套树、手动矩阵的构造说明、双投影对比截图、漫游录屏 10 秒）。

### 评分量规（10 分制）

| 维度 | 分值 | 说明 |
|---|---|---|
| 层级与变换正确性 | 3 | 三级变换嵌套正确；倾角以"先转后挂"方式实现；手造矩阵存在且正确 |
| 观察与投影 | 2 | 双投影可切换且差异正确；漫游平滑可暂停 |
| 交互与面板 | 2 | 速度 / 倾角 / 轨道线控件全部生效 |
| 代码质量 | 1 | 天体参数（半径、距离、周期）集中配置，便于调整 |
| README 与演示 | 1 | 含变换嵌套树图与矩阵说明，现场演示流畅 |
| 选做扩展 | +2 | 按完成度给分，封顶 +2 |

## AP3 · 光照与纹理场景（10 分，W8 发布 → W11 末交）

### 项目目标

- 掌握 Phong 光照模型三个分量（环境 / 漫反射 / 镜面）及参数调节；
- 掌握纹理映射流程与 UV 坐标、环境贴图反射、阴影贴图；
- 综合运用拾取交互实现"选中即调参"。

### 任务分解

**必做（Baseline，满分 8 分）**

1. **场景搭建**：一个房间或庭院场景，≥ 5 个物体、≥ 2 种光源（方向光 + 点光），地面可接收阴影。
2. **手写 Phong 着色器**：顶点 / 片元着色器实现 Phong 模型（教材 Ch6），环境光强度、漫反射颜色、镜面强度、高光指数以 uniform 暴露，参数面板实时调节；提供"三分量独立开关"（环境 / 漫反射 / 镜面各一个勾选框），README 附四种组合（只开环境、只开漫反射、只开镜面、全开）的对比截图。
3. **普通纹理**：至少一个物体使用位图纹理（`gl.texImage2D` + 纹理坐标 attribute + 片元着色器采样），README 画出该物体的 UV 展开示意并解释"顶点 UV → 纹理采样 → 片元颜色"数据流。
4. **环境贴图**：一个高反射物体（球体或立方体即可）使用立方体环境贴图（cubemap，教材 7.6 reflection mapping）。
5. **阴影贴图**：实现阴影贴图——第一遍将场景深度渲染到帧缓冲对象（FBO）纹理，第二遍比较深度生成阴影（教材 Ch8.8，可参考官网阴影示例代码）；阴影相机参数可经面板调节，观察阴影锯齿 / 漏光变化，README 简述两遍渲染原理。
6. **拾取调参**：鼠标点击拾取物体（教材 3.9 拾取思想：颜色编码拾取或射线求交，自行实现），被选中物体高亮（描边 / 变色），参数面板随即切换为该物体的材质参数。

**选做（Extension，最多 +2 分）**

- E1：法线 / 凹凸贴图对比展示；
- E2：点光源阴影或透明物体（`blend` 混合）效果；
- E3：实现 Blinn–Phong 变体或卡通着色（toon shading），与原 Phong 并排对比。

### 交付物

可运行 URL + 源码 zip + README（含三分量对比截图 4 张、UV 数据流图、阴影两遍渲染原理简述、拾取交互操作说明）。

### 评分量规（10 分制）

| 维度 | 分值 | 说明 |
|---|---|---|
| 光照正确性 | 3 | Phong 三分量调参正确，对比截图齐全 |
| 纹理与环境贴图 | 2 | 普通纹理 + 环境贴图均正确，UV 解释到位 |
| 阴影 | 2 | 阴影贴图正确渲染且参数可调，原理说明正确 |
| 拾取交互 | 1 | 点击拾取 + 高亮 + 参数联动完整 |
| 代码与文档 | 1 | 模块化（场景 / 着色器 / UI 分文件），文档完整 |
| 选做扩展 | +2 | 按完成度给分，封顶 +2 |

## 与 Term Project 的衔接

- 三个 Assigned Project 均为**个人基础能力验收**；Term Project（70%，W12 选题、W14 答辩）为**团队协作综合项目**，须覆盖场景图、曲线曲面、光线追踪、粒子系统等 AP 之外的知识点（选题清单与里程碑见《课程项目指导书》）。
