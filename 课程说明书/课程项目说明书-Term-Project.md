## 二、选题详解

### 选题 1：CPU 光线追踪器（参考 *Ray Tracing in One Weekend*）

自底向上实现一个 Whitted 风格递归光线追踪器，理解"从像素出发逆向追光"的渲染范式。**工作量：大。**

- **必做**
  1. 针孔相机模型：为每个像素生成主射线，支持 `gl.drawPixels` 等价输出（canvas 2D 或 WebGL 纹理显示）；
  2. 射线求交：球体与平面至少各一种解析求交，场景由代码描述（≥ 5 个物体）；
  3. 局部光照：Blinn–Phong + 阴影射线（硬阴影）；
  4. 镜面反射：递归反射（≥ 2 层），反射率可调；
  5. 抗锯齿：超采样（≥ 2×2）或抖动采样。
- **选做**
  - 折射：Snell 定律 + 全内反射（玻璃材质）；
  - 三角形网格求交 + OBJ 模型加载（Utah 茶壶上线）；
  - 程序化天空盒 / 棋盘地面等程序化材质；
  - BVH 或包围盒加速；Web Worker 并行渲染；简化路径追踪（间接光照）。

### 选题 2：3D 小游戏

完整可玩的 3D 小游戏，图形学重点在变换、观察、拾取、动画与碰撞。**工作量：中。**

- **必做**
  1. 完整游戏循环：目标、胜负判定、重开；HUD（分数 / 计时 / 提示，HTML overlay 实现）；
  2. 一种相机方案（第一人称 / 第三人称跟随 / 轨道）；
  3. 碰撞检测：AABB 或包围球级别即可，须与游戏机制绑定（吃、挡、弹）；
  4. 拾取交互（教材 3.9 思想）；
  5. 至少一处动画：移动、旋转或关键帧。
  - 示例：3D 贪吃蛇、桌面冰球、迷宫寻宝、弹珠台。
- **选做**：AI 对手（简单状态机）；关卡编辑或随机生成；粒子特效（爆炸 / 火花）；雾效 / 阴影增强氛围；音效。

### 选题 3：粒子系统

实现一个通用粒子系统框架，跑通至少两种视觉效果。**工作量：中。对应教材 Ch10。**

- **必做**
  1. 发射器模型：发射位置 / 速率 / 初速度分布 / 生命周期，参数面板可调；
  2. 力场：重力、阻尼，至少再加一种（风力 / 斥力场）；
  3. 两种以上效果：喷泉、烟花、爆炸任选其二；颜色与透明度随生命周期变化（`blend` 混合）；
  4. 渲染：`gl.POINTS` + `gl_PointSize` + 点精灵纹理；
  5. 粒子与场景有交互（如落到地面消亡或反弹）。
- **选做**：CPU 更新迁移至 GPU（WebGL 2.0 transform feedback）；烟 / 尘类软粒子近似；烟花编排脚本（JSON 定义节奏）。

### 选题 4：程序化地形

用噪声或分形算法生成可漫游的三维地形。**工作量：中。对应教材 Ch10 程序化方法。**

- **必做**
  1. 高度场生成：中点位移或 Perlin / Simplex 噪声（可自行实现或注明引用），种子可换；
  2. 高度→视觉映射：按高度 / 坡度着色（雪线、草地、岩壁）；
  3. 顶点法线计算与光照（复用 AP3 的 Phong 经验）；
  4. 飞行或漫游相机，可在地形上自由移动；
  5. 雾效与合理的天空 / 背景色。
- **选做**：水面（动画波纹 + 简易反射）；昼夜循环（光源方向与颜色随时间变化）；基于距离的细分 / LOD 或视锥裁剪优化。

### 选题 5：关节角色动画（层次建模）

以矩阵栈为核心的层次建模与关节动画。**工作量：中。对应教材 Ch9 + Ch11。**

- **必做**
  1. ≥ 5 个关节的层次结构（机械臂或小人，如肩–肘–腕或髋–膝–踝），矩阵栈遍历渲染；
  2. 键盘或滑条实时控制各关节角，限位（关节活动范围）；
  3. 关键帧动画：录制—插值—播放一段动作（挥手 / 走路 / 抓取）；
  4. 正运动学演示 + 简单的两关节逆运动学（末端触达鼠标指定点）。
- **选做**：全身 IK（CCD / FABRIK）；程序生成行走步态；抓取—搬运—放置的物体交互；关键帧插值改用 Bézier 曲线（衔接 Ch11）。

### 选题 6：Bézier / B 样条曲线曲面编辑器

交互式曲线设计与曲面生成。**工作量：中偏小。对应教材 Ch11。**

- **必做**
  1. 交互控制点：添加、删除、拖拽，实时更新曲线；
  2. 两种求值实现并对比：de Casteljau 几何作图法与 Bernstein 多项式法；
  3. 曲线细分段数可调；多段拼接并说明连续性（C0 / C1）；
  4. 旋转曲面：曲线绕轴生成网格，加光照渲染；
  5. 展示一个由曲线曲面构成的完整物体（酒杯、花瓶、茶壶；可加载官网 teapot 数据）。
- **选做**：B 样条 / Catmull–Rom 基函数切换；双三次 Bézier 曲面片；物体沿曲线运动的扫掠动画。
